## Goal

You can name and write the four kinds of test double, and choose between them by what the test needs to observe.

In the lesson: Before the four doubles, here is the two line seam they all exercise. Pay delegates to the gateway and returns the reference it receives. The lesson can now run each test in one workspace with the boundary visible, which is how a learner would build it in an editor. The double changes from screen to screen, while the contract stays put.
