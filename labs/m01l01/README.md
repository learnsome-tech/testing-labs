Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Your turn: price a claim before you write it

1. Pick a function you own and write the one sentence a test of it would check.
2. Write that test, run it green, then break the function on purpose and read the report.
3. Now estimate the cost: who edits this test when the behaviour changes on purpose?

> **Hint:** If the sentence needs the word and, you have found two claims, not one.

## Check yourself

- What does a test buy you that a careful manual check does not?
- Name two costs a test adds to a codebase.
- Which four facts does the pytest failure report give you?
- Why is a test nobody trusts worse than having no test at all?
- What kind of assertion makes a test break on every refactor?
