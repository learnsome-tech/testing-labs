# Exercises — The Cost And Value Of A Test

Lesson `m01l01` · [Watch](https://learnsome.tech/courses/testing-course/watch?lesson=m01l01)

## Exercise 1: Your turn: price a claim before you write it

1. Pick a function you own and write the one sentence a test of it would check.
2. Write that test, run it green, then break the function on purpose and read the report.
3. Now estimate the cost: who edits this test when the behaviour changes on purpose?

> **Hint**: If the sentence needs the word and, you have found two claims, not one.
