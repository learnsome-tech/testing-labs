## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Your turn: read your own collection

1. Run the collect only flag on one package of your suite and read the names aloud.
2. Rewrite the three worst names as sentences about behaviour, then collect again.
3. Check that a keyword search for one domain word now selects the right tests.

> **Hint:** If a name needs the file it lives in to make sense, it is not finished.

## Check yourself

- Why is a test name more important than a comment inside the test?
- What three parts make a good test name?
- What does the collect only flag give you, and what does it cost?
- How do good names change what the keyword flag can do for you?
